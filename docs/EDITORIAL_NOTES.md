# Editorial notes for the 2026-10-04 snapshot

This first release prioritizes a broad and useful core over a claim of universal completeness. AI changes too quickly for any static directory to be final.

The snapshot incorporates major 2026 affiliation changes including Discovery Loop and moves involving senior frontier-model researchers. Counts include entities rather than individual social profiles; GitHub YouTube X LinkedIn Hugging Face and Scholar links are attached to the owning entity.

Current gaps suitable for future pull requests include more verified sources in Arabic Chinese Japanese Korean Portuguese Russian and Spanish; additional African and Latin American university laboratories; specialist AI in agriculture climate law and manufacturing; and official accounts on region-specific social platforms.

Some institutional sites reject automated probes or use older TLS configurations. Those records are retained when their identity is supported by primary institutional sources.
